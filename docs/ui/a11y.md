# Accessibility

The framework keeps a semantics tree beside the render tree. It is built after layout.
A node has a role, a label, a value, flags, a rectangle in logical pixels, and actions.
`app.dump` prints one line per node:

```
sem|id|role|label|x|y|w|h
```

`m_*` widgets publish that record. A `semantics.wrap` with `hide` true replaces every
announcement in its subtree, so a button is one node rather than a button plus its text.
Without `hide`, the node is a parent and descendant nodes stay. A text or image that no
widget has described becomes a `text` or `image` node, unless an ancestor label is that
same string. A gesture with no semantics ancestor becomes a `button`.

Roles are `button checkbox switch slider text_field header dialog list_item group
separator progress status text image`. Flags are `focusable` (1), `checked` (2),
`disabled` (4), and `selected` (8). Actions are `tap` (1), `focus` (2), `set_value` (4),
`dismiss` (8), and `scroll` (16).

## Record

Kind 9 on the 64-byte host record is an accessibility action. `a` is the action bit,
`b` is the node id, and `c` is the byte count of a `set_value` string in the 32 bytes
at offset 32. The null host also accepts `act|tap|ID`, `act|focus|ID`, `act|dismiss|ID`,
`act|scroll|ID`, and `act|value|ID|TEXT`. Tap and dismiss run the target gesture's
message. Focus moves focus there. `set_value` replaces a field's text or a slider's
0..100 value. Scroll uses the wheel path.

## Blob

`host.a11y` receives one little-endian buffer. A `u32` count, then each node: `u32` id,
parent, role, flags, actions, four `f32`s (`x y w h`), a `u32` length and that many
label bytes, then the same for the value. Parent `0xFFFFFFFF` is a root.

## Platforms

Windows exposes the blob through a UI Automation fragment root on the window.
macOS builds `NSAccessibilityElement`s. iOS builds `UIAccessibilityElement`s. Android
installs `llr.ui.A11y` on the activity's decor view when that class is in the APK;
`llr-ui pack` compiles it when `javac` and `d8` are present. The web host keeps a
hidden DOM mirror behind the canvas, with ARIA roles and `tabindex`, and sends focus
and activation back as kind 9. Linux AT-SPI is later: the X11 shim accepts the blob
and does not publish it. The suite stays headless.
