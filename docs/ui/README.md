# ui index

Pages are generated by `llr-doc --out docs/ui`. Import a module with `(use ui.name)`.
A trait in another module is `module.Trait`, and a method is `module.Trait.method`.
A method on a type with the same name as its module is `module.Type.method`
(`key.key.none`, `ctx.ctx.root`, `host_null.host_null.from_args`).

`ctx.theme` is a background and foreground pair. The Material theme in `ui/theme.llr`
is phase 11. Custom render objects are leaves: `row`, `column`, and `stack` are
framework layout.

| module | role |
|--------|------|
| [host](host.md) | Platform surface. The framework paints; a host only presents pixels and reports events. |
| [host_null](host_null.md) | Headless host. Size and events come from argv; present writes a PPM when `--shot` is set. |
| [event](event.md) | Pointer, key, text, and script records. |
| [key](key.md) | Optional widget key. Both absent keys match; a present key matches only the same id. |
| [ctx](ctx.md) | Build snapshot. `size` is the host, not the element. Ancestors are nearest first. |
| [widget](widget.md) | Widget trait, leaf descriptors, and stateless. Type ids stand in for a runtime type. |
| [state](state.md) | Stateful widgets. The element keeps the first state; a later widget's init is dropped. |
| [element](element.md) | Element arena. Reconciliation keeps a child when its type id and key match. |
| [render](render.md) | Render arena. Ids stay put; a dead node is skipped. Custom objects are leaves. |
| [layout](layout.md) | Pure flex and stack numbers. |
| [render_box](render_box.md) | Box layout. A clean relayout boundary keeps its size when constraints match. |
| [render_paint](render_paint.md) | Paint into one bitmap. Opacity, clip, and transform isolate their children. |
| [hit](hit.md) | Deepest gesture whose rect contains the point. Later children are in front. |
| [focus](focus.md) | Tab order is the preorder of gesture elements. |
| [sched](sched.md) | One frame's events: hit, messages, focus, then the caller rebuilds. |
| [app](app.md) | Opens a tree, runs frames, and dumps it. The first layout happens before events. |
| [w_box](w_box.md) | Container, padding, sized box, align, and center. |
| [w_flex](w_flex.md) | Row, column, expanded, and flex. |
| [w_stack](w_stack.md) | Stack and positioned. |
| [w_text](w_text.md) | A single-style paragraph. |
| [w_image](w_image.md) | An image sized to its bitmap, in logical pixels. |
| [w_gesture](w_gesture.md) | A tap target. The closure returns a message id; 0 means none. |
| [w_fx](w_fx.md) | Opacity, clip, and transform. They are repaint boundaries. |
