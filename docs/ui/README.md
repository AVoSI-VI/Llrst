# ui index

Pages are generated by `llr-doc --out docs/ui`. Import a module with `(use ui.name)`.
A trait in another module is `module.Trait`, and a method is `module.Trait.method`.
A method on a type with the same name as its module is `module.Type.method`
(`key.key.none`, `ctx.ctx.root`, `host_null.host_null.from_args`).

`ctx.theme` is a `ctx.palette`: eight colours, three text sizes, and a spacing unit.
`theme.light` and `theme.dark` are the two bundled palettes; `w_theme.dark` swaps
the palette for its descendants. Custom render objects are leaves: `row`, `column`,
`stack`, and `scroll` are framework layout.

| module | role |
|--------|------|
| [host](host.md) | Platform surface. The framework paints; a host only presents pixels and reports events. |
| [host_null](host_null.md) | Headless host. `--frames` and `--step` drive the clock; `--shot` writes a PPM. |
| [host_shim](host_shim.md) | Platform shim calls. The linked object is chosen from the target. |
| [host_win](host_win.md) | Win32 host. The shim object is chosen at link time. |
| [host_x11](host_x11.md) | X11 host. The shim object is chosen at link time. |
| [host_mac](host_mac.md) | Cocoa host. The shim object is chosen at link time. |
| [host_android](host_android.md) | Android host. The shim object is chosen at link time. |
| [host_ios](host_ios.md) | iOS host. The shim object is chosen at link time. |
| [host_pick](host_pick.md) | Picks the desktop host from the operating system. |
| [hosts](hosts.md) | Win32, X11, and Cocoa manual check. The suite stays headless. |
| [mobile](mobile.md) | Android and iOS hosts and `llr-ui pack`. The suite stays headless. |
| [event](event.md) | Pointer, key, text, life, inset, and script records. `take_rec` reads the 64-byte host record. |
| [key](key.md) | Optional widget key. Both absent keys match; a present key matches only the same id. |
| [ctx](ctx.md) | Build snapshot. `size` is the host, not the element. Ancestors are nearest first. |
| [widget](widget.md) | Widget trait, leaf descriptors, and stateless. Type ids stand in for a runtime type. |
| [state](state.md) | Stateful widgets. The element keeps the first state; a later widget's init is dropped. |
| [element](element.md) | Element arena. Reconciliation keeps a child when its type id and key match. |
| [render](render.md) | Render arena. Ids stay put; a dead node is skipped. Custom objects are leaves. |
| [layout](layout.md) | Pure flex and stack numbers. |
| [render_box](render_box.md) | Box layout. A clean relayout boundary keeps its size when constraints match. |
| [render_paint](render_paint.md) | Paint into one bitmap. Opacity, clip, and transform isolate their children. |
| [hit](hit.md) | Deepest gesture whose rect contains the point. Later children are in front. |
| [focus](focus.md) | Tab order is the preorder of gesture elements. |
| [sched](sched.md) | One frame's events: hit, messages, focus, then the caller rebuilds. |
| [app](app.md) | Opens a tree, runs frames, and dumps it. The first layout happens before events. |
| [curve](curve.md) | Unit curves. `ease_in`, `ease_out`, and `ease_in_out` are the CSS cubics. |
| [tween](tween.md) | Linear interpolation of floats, colors, rects, and sizes. |
| [anim](anim.md) | Controller, implicit target, and the track a ticker stores. |
| [ticker](ticker.md) | Per-frame ticks. States run before rebuild; implicit tracks write the render desc after. |
| [w_box](w_box.md) | Container, padding, sized box, align, and center. |
| [w_flex](w_flex.md) | Row, column, expanded, and flex. |
| [w_stack](w_stack.md) | Stack and positioned. |
| [w_text](w_text.md) | A single-style paragraph. |
| [w_image](w_image.md) | An image sized to its bitmap, in logical pixels. |
| [w_gesture](w_gesture.md) | A tap target. The closure returns a message id; 0 means none. |
| [w_anim](w_anim.md) | Builder and implicit leaves. A leaf keeps its child; the ticker rewrites the render desc. |
| [w_fx](w_fx.md) | Opacity, clip, and transform. They are repaint boundaries. |
| [theme](theme.md) | Light and dark palettes. Descendants read them through `ctx.theme`. |
| [w_theme](w_theme.md) | A theme for the descendants of one widget. Key `1` means dark. |
| [ptrs](ptrs.md) | Pointer, focus, and animation tracks for one frame. |
| [input](input.md) | Pointer drags, wheels, keys, text, and clipboard. A false message walks upward. |
| [scroll](scroll.md) | Vertical offset. Clamped to the content, with a fling that dies at the edge. |
| [w_scroll](w_scroll.md) | A viewport that clips its child and shifts it by the scroll offset. |
| [w_list](w_list.md) | Fixed-extent list. Only the rows in the host window are mounted. |
| [m_shell](m_shell.md) | Scaffold and app bar. |
| [m_button](m_button.md) | Filled button and icon button. The icon is a label in the bundled font. |
| [m_field](m_field.md) | One-line field. It owns the string, the caret, and the selection. |
| [m_toggle](m_toggle.md) | Checkbox, switch, and a slider that owns a value from 0 to 100. |
| [m_layer](m_layer.md) | Dialog scrim and a snack bar that leaves after a short tick. |
| [m_tile](m_tile.md) | List tile, card, divider, and a determinate progress bar. |
| [m_show](m_show.md) | One column of every named control, for the light and dark goldens. |
| [navigator](navigator.md) | A stack of routes. Push slides the new page in; pop slides it back out. |
